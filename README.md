# 🃏 Super Trunfo - Batalha de Cartas em C

Projeto desenvolvido como parte de um desafio lógico-programacional, utilizando a linguagem C.  
Neste desafio, duas cartas contendo dados de cidades "lutam" entre si com base em seus atributos como população, PIB, área, densidade populacional e outros, incluindo um cálculo especial chamado **Super Poder**.

---

## ✅ Funcionalidades Implementadas

### ✔️ Requisitos Funcionais

- [x] Leitura completa dos dados de duas cartas Super Trunfo
- [x] Uso do tipo `unsigned long int` para armazenar população
- [x] Cálculo da **Densidade Populacional**
- [x] Cálculo do **PIB per Capita**
- [x] Cálculo do **Super Poder** com base nos atributos (inclusive o inverso da densidade)
- [x] Comparação atributo por atributo entre as cartas:
  - População
  - Área
  - PIB
  - Número de Pontos Turísticos
  - **Densidade Populacional** (menor vence)
  - PIB per Capita
  - Super Poder
- [x] Impressão clara de quem venceu cada atributo (1 = Carta 1 venceu, 0 = Carta 2 venceu)

### 🧠 Requisitos Não Funcionais

- [x] Código organizado e de fácil leitura
- [x] Comentários explicativos nos principais pontos
- [x] Uso adequado dos operadores e tipos
- [x] Eficiência no cálculo e estrutura geral
- [x] Saída de dados organizada e bem apresentada ao usuário

---
